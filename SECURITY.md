# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in the Car List API Laravel SDK, **please do not create a public GitHub issue.**

Instead, use GitHub's **Private Vulnerability Reporting** feature:

https://github.com/Codebyray/carlistapi-laravel-sdk/security/advisories/new

Please include:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested mitigation (if known)

We will acknowledge your report as quickly as possible and work to resolve verified issues promptly.

---

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | ✅ |
| < 0.1   | ❌ |

## Framework Compatibility

Security support for this SDK does not extend the support lifecycle of Laravel
or PHP.

The SDK may remain technically compatible with framework versions that have
reached end-of-life. Applications should use a Laravel and PHP version that
still receives upstream security updates.
